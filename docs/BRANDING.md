# DenizSigner icon

Source: `public/logo-icon.png` (transparent PNG). The same image is used in the
app and documentation. `npx tauri icon public/logo-icon.png` regenerates desktop,
Windows, macOS and mobile icon sizes. The light azure brand color is `#2F7BFF`;
the interface uses this color with a lighter `#4B9CFF` gradient edge.

Created with the built-in Imagegen tool, with this prompt:

> Use case: logo-brand. Create the finished production app icon for DenizSigner,
> a private desktop code-signing application. A single macOS-style rounded square
> / continuous squircle tile, front facing orthographic, centered with a small
> transparent margin. Main tile background is luminous light azure blue, precisely
> #2F7BFF, matching the application's light blue interface. Center a bold, refined
> white letter D, custom rounded monogram, with one subtle fountain-pen nib cutout
> integrated into its lower curve to suggest signing. Clean modern macOS aesthetic,
> restrained soft dimensionality and a fine top-edge highlight, exceptionally
> readable at 32 pixels, elegant and minimal. The tile must have rounded macOS app
> icon corners and transparent outer corners, NOT a square black background. No
> orbit rings, no metallic chrome, no shields, no extra letters or words, no
> watermark, no mockup, no desktop scene. Deliver only the icon asset, square
> composition, high resolution.
